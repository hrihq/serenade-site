# Serenade — situs

Halaman promosi unduh untuk aplikasi Android Serenade.

- `index.html` — halaman mandiri (CSS + JS inline, tanpa build step).
- `assets/icon.png` — ikon aplikasi (1024×1024).
- `assets/serenade-1.6.apk` — APK rilis v1.6 yang dibagikan ke pengguna.

Deploy otomatis ke GitHub Pages lewat `.github/workflows/pages.yml`.

Mockup ponsel dan widget di halaman adalah ilustrasi antarmuka berbasis CSS,
bukan tangkapan layar asli. Ganti dengan screenshot bila tersedia.
